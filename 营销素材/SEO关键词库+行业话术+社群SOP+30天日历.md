# 第二部分：行业切入话术库

## 五金/建材/机电行业
**切入语**：
> "你店里的销售和仓库，是不是经常因为发货慢扯皮？明明客户等着要，仓库说没收到单子。其实不是人坏，是没有规则把两边的协作变成可记录的东西。我们有套规则——给销售和仓库之间设了助攻分。谁帮谁反应快，谁就加分。"

**关键痛点词**：发货慢、型号乱、仓库销售扯皮、老客户流失
**推荐规则包**：门店服务稳定型 → 后勤助攻协作型

## 美容/美发/养生行业
**切入语**：
> "你店里最勤快的美容师，是不是很少被客人点名表扬？因为客人习惯了口头夸一句，夸完就走了，没法记录。我们帮这种'看不见的贡献'变成可记录的数据——谁经常帮同事顶班、谁安抚了闹退卡的客户、谁下班还在回微信。记录在案，月末一看就知道谁是真勤奋。"

**关键痛点词**：好人吃亏、看不见的努力、客流波动、退卡
**推荐规则包**：门店服务稳定型

## 餐饮/奶茶/连锁门店
**切入语**：
> "餐饮行业最大的痛：好的后厨师傅不带新人。新人三个月还不会上灶——不是笨，是师傅觉得浪费时间。我们把'带徒弟'变成师傅绩效的一部分——徒弟的进步直接算师傅的分。师傅发现不带徒弟排名会掉，就开始主动申请带人了。"

**关键痛点词**：老人不教、新人走、出餐不稳、客流高峰
**推荐规则包**：老员工激活型 + 新人保护型

## 装修/工程/安装行业
**切入语**：
> "装修公司最累的，不是找客户——是销售签了单，工程说做不出来；工程说要加钱，销售说预算不够。每天在中间调解。我们搞了一套助攻分——销售和施工之间的协作变成可记录的数据。谁帮对方解决了问题，系统自动记录加分。两个月后推诿投诉降了70%。"

**关键痛点词**：扯皮、返工、工期拖延、客户投诉
**推荐规则包**：销售团队冲刺型 + 后勤助攻协作型

## 招商/加盟/房产中介
**切入语**：
> "招商团队最怕新人大进大出。招回来一批，三个月走一半。原因很简单：新人来了直接和老销售比排名——根本没法比，心态先崩。我们有新人保护舱——前3个月不参与排名，只考核学习和进步。同时师傅的绩效和徒弟绑定。留任率从40%提到了78%。"

**关键痛点词**：新人走、线索分配不公、留存低
**推荐规则包**：销售团队冲刺型 + 新人保护型

## 科技/研发/软件公司
**切入语**：
> "技术团队干了一个季度没出活，月度考核排名全部垫底——因为他们做的攻关短期看不到结果。我们有长周期项目保护型规则包，做难事的不参与月度结果排名，只考核里程碑和过程。让做底层工作的人不吃闷亏。"

**关键痛点词**：研发考核难、项目周期长、月度评分不公平
**推荐规则包**：长周期项目保护型

## 财税/代账/咨询公司
**切入语**：
> "财税行业有个常见难题：有人报表出错率高，有人客户回得慢。但你想提醒又不好意思说重了——因为都是专业人员。我们有系统自动提醒功能，不劳你开口，系统用数据说话。出错率高的收到一条提醒，私下就改了。"

**关键痛点词**：社恐领导、专业人员不好说、隐性错误
**推荐规则包**：后勤助攻协作型 + 系统代提醒模式

## 快递/配送/物流行业
**切入语**：
> "配送团队有个问题：最好的骑手不是接单最多的，而是配合最好、救急最多、从不拒单的。但他从来不被单独表扬。我们的助攻榜和配合分系统，帮这种人的每一天忙碌都留下了痕迹。他拿到红榜那天，跟你说把辞工申请收回去了。"

**关键痛点词**：好员工不被看到、配合价值无法量化
**推荐规则包**：后勤助攻协作型

# 第三部分：社群SOP运营手册

## 社群定位
- **群名称**：「傻瓜绩效管人」小老板交流群
- **人群**：5-50人小微企业老板/店长/管理者
- **价值主张**：帮小老板从"天天盯人"里解放出来
- **群规3条**：①不广告 ②不吵架 ③问题随时问，每天集中回复

## 群角色
| 角色 | 职责 |
|------|------|
| 群主（品牌IP） | 发干货、讲案例、答疑 |
| 小助手 | 欢迎新人、发资料、引导互动 |
| KOC（种子用户） | 分享使用体验、回应新成员问题 |

## 每日SOP

| 时间 | 动作 | 示例 |
|:----:|------|------|
| 9:00 | 早安+今日话题 | "早上好各位老板☀️ 今天的话题：你团队里'最不该被忽视的人'是谁？@出来给他一个公开表扬👇" |
| 12:00 | 午间干货 | 发一条管人小技巧/规则包片段 |
| 17:00 | 互动/投票 | "测一下你公司的管人健康度：□好员工走得突然 □差员工不敢说 □做决定靠感觉 □推诿扯皮 □表扬总漏人。中3条以上的扣1" |
| 20:00 | 晚间故事 | 发一段客户真实故事（100-200字） |

## 每周节奏

| 星期 | 主题 | 内容形式 |
|:----:|------|---------|
| 周一 | 痛点共鸣 | 短片/故事/匿名投票 |
| 周二 | 干货技巧 | 小老板管人小贴士 |
| 周三 | 产品互动 | 规则包匹配自测/投票 |
| 周四 | 案例分享 | 客户真实故事+截图 |
| 周五 | 福利转化 | 免费试用名额/资料包 |
| 周六 | 老板茶话会 | 自由交流+群主答疑 |
| 周日 | 下周预告 | 下周话题投票 |

## 新人欢迎流程
1. 自动@新人："欢迎XX老板！👋 这里有一群和你一样的小老板在交流管人经验。"
2. 发送资料包：《小老板公平管人实战指南》+ 30天免费试用链接
3. 引导互动："你公司多少人？什么行业？最大的管人难题是什么？"
4. 48小时内不互动 → 私聊跟进

## 沉默用户激活
| 天数 | 动作 |
|:----:|------|
| 7天未发言 | 发新资料/新故事 |
| 14天未发言 | 私聊："老板，最近是不是太忙？上周出了个新案例，发你看看" |
| 30天未发言 | 最后一封："如果需要随时回来，链接一直有效" |
